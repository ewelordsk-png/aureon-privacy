# Aureon – Zásady ochrany súkromia / Privacy Policy ## Slovenčina **Aplikácia:** Aureon (sk.aureon.game) **Vydavateľ:** Raven Meridian **Kontakt:** ewelordsk@gmail.com **Verzia:** 0.24.4, bezplatná verzia **Aktualizované:** 10. novembra 2026 ### 1. Spracúvanie údajov Aureon funguje offline a nevyžaduje vytvorenie používateľského účtu. Aplikácia nezhromažďuje ani automaticky neodosiela osobné údaje vydavateľovi. Nemá vlastný server, reklamné siete, analytické služby ani automatické odosielanie hlásení o chybách. ### 2. Údaje uložené v zariadení V súkromnom úložisku aplikácie sa uchovávajú herný postup, virtuálne investície, kariéra, majetok, herné transakcie, vlastné názvy, nastavenia a obnovovacie zálohy. Tieto údaje slúžia na pokračovanie v hre. Interné súbory herného postupu sú chránené šifrovaním pomocou Android Keystore. Automatické zálohovanie aplikácie cez Android je vypnuté. ### 3. Export a import záloh Používateľ môže dobrovoľne exportovať herné údaje do súboru JSON, ktorý nie je samostatne šifrovaný. Miesto uloženia vyberá používateľ. Ak použije cloudové úložisko, súbor môže spracúvať vybraný poskytovateľ podľa svojich pravidiel. Vydavateľ exportované súbory automaticky nedostáva. ### 4. Oprávnenia a externé služby Aplikácia nevyžaduje prístup k polohe, kontaktom, fotoaparátu, mikrofónu ani SMS. Táto verzia neobsahuje reklamy, aktívne nákupy v aplikácii, predplatné, online účty ani Android widget. Na výber súborov záloh používa systémové rozhranie Androidu. ### 5. Uchovávanie a odstránenie Herné údaje zostávajú v zariadení, kým ich používateľ neodstráni. Všetky miestne údaje možno odstrániť cez Nastavenia Androidu → Aplikácie → Aureon → Úložisko → Vymazať údaje alebo odinštalovaním aplikácie. Exportované zálohy musí používateľ odstrániť osobitne. ### 6. Kontakt a zmeny Otázky týkajúce sa súkromia možno posielať na ewelordsk@gmail.com. Ak používateľ sám odošle e-mail, vydavateľ spracúva informácie, ktoré mu dobrovoľne poskytne, na vybavenie jeho požiadavky. Pri zmene funkcií alebo spracúvania údajov budú tieto zásady aktualizované. --- ## English **Application:** Aureon (sk.aureon.game) **Publisher:** Raven Meridian **Contact:** ewelordsk@gmail.com **Version:** 0.24.4, free release **Updated:** November 10, 2026 ### 1. Data processing Aureon operates offline and does not require a user account. The application does not collect or automatically transmit personal data to the publisher. It has no application server, advertising networks, analytics services or automatic crash reporting. ### 2. Locally stored information The application stores game progress, virtual investments, career information, assets, in-game transactions, custom names, preferences and recovery backups in private application storage. These records are used to maintain game progress. Internal game-progress files are encrypted using Android Keystore. Automatic Android application backup is disabled. ### 3. Backup export and import Users may voluntarily export their game progress to a JSON file. Exported files are not separately encrypted. Users select the destination. If a cloud provider is selected, that provider may process the file under its own privacy policy. The publisher does not automatically receive exported backups. ### 4. Permissions and third-party services The application does not request access to location, contacts, camera, microphone or SMS. This version does not include advertisements, active in-app purchases, subscriptions, online accounts or Android widgets. Android's system file picker is used for backup selection. ### 5. Retention and deletion Game records remain on the device until deleted by the user. Local application data can be removed through Android Settings → Apps → Aureon → Storage → Clear data, or by uninstalling the application. Previously exported backups must be deleted separately by the user. ### 6. Contact and updates Privacy questions can be sent to ewelordsk@gmail.com. If users voluntarily contact the publisher by email, the information they provide is used to respond to their request. This policy will be updated if the application's features or data processing practices change.
